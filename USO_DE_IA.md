# Declaración de uso de IA

Usé Codex como apoyo para estructurar el proyecto, revisar requisitos y generar un borrador. Revisé y adapté el código para mantenerlo simple: controladores, servicios, DTOs, EF Core, migraciones y consultas LINQ. No se aceptó ningún secreto dentro del repositorio. Entiendo el flujo de cada endpoint, el hash de contraseñas con `PasswordHasher` y el cifrado AES-GCM de los campos sensibles.
